# Security policy

## Supported version

Security reports are accepted for the latest code on the default branch.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** flow in the repository Security tab rather than posting exploit details in a public issue. Include the affected version, impact, and a minimal reproduction. Do not attach user databases, private prompts, credentials, or model files.

The runtime is intended for local use. If you expose its API beyond localhost, put it behind an appropriate authentication and network boundary; the MVP does not implement API authentication.
