# Support

For bugs, open a [bug report](https://github.com/supermemeseveryday-star/experience-ai-runtime/issues/new?template=bug_report.yml). For ideas, use the feature request template. For usage questions, start a discussion if GitHub Discussions are enabled, or open a question issue.

Before reporting an Ollama problem, run `experience-ai health` and check that the configured model appears in `ollama list`. Unit tests do not require Ollama.
