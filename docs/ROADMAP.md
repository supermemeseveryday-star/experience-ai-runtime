# Roadmap

This roadmap describes directions, not promises or release dates.

## Near term

- Add labeled, reproducible quality benchmarks and evaluator plugins.
- Improve semantic retrieval evaluation across English and Chinese queries.
- Add database schema migrations and an experience export/import format.
- Add domain-specific validators and a clearer review workflow.
- Add reliable token accounting when the local provider exposes usage data.

## Later

- Add optional local embedding backends with explicit model setup.
- Add skills to the retrieval and routing loop.
- Explore alternate local model adapters and vector indexes behind existing interfaces.

## Out of scope for the MVP

- Cloud LLM APIs, telemetry, and automatic web scraping.
- Fine-tuning or modifying model weights.
